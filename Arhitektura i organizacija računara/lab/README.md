# Arithmetic Operations and Processor Flags in x86 Assembly

This project demonstrates low-level arithmetic operations in x86 Assembly, focusing on signed integer arithmetic, register manipulation, carry propagation, division, and arithmetic shifts.

## Key Concepts

- **Register operations:** Working with 16-bit and 32-bit registers (`AX`, `EAX`, `EBX`, `ECX`, `EDX`).
- **Sign extension:** Using `MOVSX` to preserve signed values when extending operands.
- **Bitwise operations:** Applying `AND` and `OR` for bit masking and bit manipulation.
- **Arithmetic operations:** Performing subtraction and signed multiplication with `SUB` and `IMUL`.
- **Carry propagation:** Using `ADC` to propagate carry during multi-register arithmetic.
- **Signed division:** Using `IDIV` to calculate quotient and remainder.
- **Arithmetic shifts:** Applying `SAR` to shift signed integers while preserving the sign bit.
- **Processor flags and exceptions:** Exploring carry, overflow, zero results, division remainders, and division-by-zero errors.

## Learning Objectives

The goal is to understand how arithmetic expressions are executed at the processor level, how signed numbers are represented using two's complement, and how processor registers and flags affect the results of low-level operations.

## Technologies

- x86 Assembly
- Processor registers and flags
- Two's complement representation
- Integer arithmetic and bitwise operations
